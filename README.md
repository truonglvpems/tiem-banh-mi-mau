# Tiệm Bánh Mì Mẫu – landing page mẫu

Trang mẫu của khoá học miễn phí **"Dùng AI lập trình một landing page từ số 0"** – kênh YouTube AI Thực Chiến.
Toàn bộ HTML, CSS, JavaScript do ChatGPT (bản không cần đăng nhập) viết qua bài 2–11 của khoá học.

Tiệm Bánh Mì Mẫu là tiệm giả; món, giá là dữ liệu mẫu. Form đặt hàng chưa gửi đơn đi đâu (trang mẫu).
